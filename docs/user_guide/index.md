# User guide

The user guide explains how NodeML works and how to use each part.
Read the first three pages in order. Read the other pages when you need them.

Concepts
: {doc}`concepts` — nodes, ports, data and the registry.

Pipelines
: {doc}`pipelines` — build, compile, edit, save and load a pipeline.

Running
: {doc}`running` — train, infer and evaluate with the runner.

Built-in nodes
: {doc}`built_in_nodes` — the catalog of the nodes that NodeML supplies.

Custom nodes
: {doc}`custom_nodes` — write and register your own node.

Tuning
: {doc}`tuning` — search hyperparameters with Ray Tune.

Serving
: {doc}`serving` — serve a trained pipeline with Ray Serve.

Tracking
: {doc}`tracking` — log runs to MLflow.

Logging
: {doc}`logging` — configure the NodeML logs.

Counterfactual explanations
: {doc}`counterfactuals` — find the input changes that move a prediction into a target range.
